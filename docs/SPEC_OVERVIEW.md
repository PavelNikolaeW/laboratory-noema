# Исследовательская лаборатория — спецификация v0.1

Дата: 2026-10-06. Отдельный проект для параллельной разработки с REPL Harness.

Цель: дать человеку и агенту одну экспериментальную среду с неизвестными закономерностями, понятными рабочими заказами и наблюдаемыми результатами. Это условная лаборатория материалов, а не симулятор реальной химии и не инструкция для физических экспериментов.

## Файлы и аудитории

| Файл | Кому передавать |
| --- | --- |
| `SPEC.md` | Разработчику лаборатории: назначение, интерфейс, границы проекта |
| `PUBLIC_API.md` | Разработчикам лаборатории и харнеса; допустимо дать испытуемому агенту |
| `PRIVATE_ENGINE.md` | Только разработчику и экспериментатору: формулы, скрытые состояния, эталоны решений |
| `EXPERIMENTS.md` | Экспериментатору: сценарии и сравнение режимов |
| `IMPLEMENTATION_AND_ACCEPTANCE.md` | Разработчику лаборатории: план, тесты, критерии готовности |
| `CODEX_HANDOFF.md` | Стартовое задание отдельному агенту-разработчику |

Не помещать весь архив в доступный испытуемому агенту репозиторий знаний. Ему доступны публичная документация, операторская заявка, оборудование и публичные наблюдения. Разработчик лаборатории и испытуемый агент — разные роли.

## Статус решений

Согласовано в обсуждении: отдельный процесс лаборатории; общие действия для человека и агента; практическая передача работы технолога; скрытые правила; контрольные образцы; исследование, перенос и адаптация; шум/износ — последующие уровни.

Формулы, значения, маршруты API и формат рецепта ниже — предложенная конкретизация v0.1 для начала реализации. Это не результаты эксперимента. Их можно пересматривать до фиксации экспериментальной версии; изменять незаметно во время сравнения нельзя.

Название харнеса пока не фиксируется: Noema было предложено, но окончательный выбор не подтверждён. Рабочее имя этого отдельного проекта — `research-lab`.

Первая версия должна запускаться без LLM и без харнеса: человек может выполнить заказ из браузера, интеграционный клиент — через HTTP API.
